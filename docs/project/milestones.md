# Framework

PROVE currently plans three milestone horizons: two, four, and six months. The first demonstration target is 2026-08-27 and the first integrated outcome target is around 2026-09-30; these remain adjustable planning targets. The second and third milestone contents remain open.

The detailed first-horizon Workstreams, dependencies, Milestone Reviews, required Evidence, and scope boundaries are defined in the [Two-Month Integrated Execution Framework](/project/two-month-execution-framework.md).

# First Two Weeks: Coverage Method Review

The first priority is an operationally applicable Coverage method, not a document-only proposal or isolated prototype.

The intended capability is:

```text
Specification and Requirement input
→ verification-space representation
→ existing Scenario/Test mapping
→ Coverage calculation and evidence
→ Gap identification
→ Scenario derivation guidance
```

Verification team leaders and executives are expected to review this approach. Milestone Review 2 acceptance becomes the working condition for expanding Scenario and Test generation. Specific Coverage axes remain undefined until the verification experts complete this work.

Four verification-team packages are known inputs. The concrete demonstration specification, Feature, and package subset are not selected.

# Two-Month Required Outcome

```text
Coverage method and operational system
→ Spec–Requirement–Scenario–Test–execution Traceability
→ Requirement extraction
→ Scenario derivation
→ executable Test generation
→ real SSD execution
→ Pass/Fail determination
→ device/non-device Failure disposition
```

This outcome also requires a versioned Verification Request, Legacy and FLAIR input paths for selected examples, bidirectional Traceability, real-Hardware qualification, Knowledge governance, reproducible Agent Runs, and minimal Test Version and Package/Baseline adoption controls. These are enabling parts of the integrated vertical slice, not separate tool-delivery milestones.

# Two-Month Stretch Outcome

If external BRAIN support is available, automatically hand off device failures and start BRAIN AI analysis.

# Four- and Six-Month Outcomes

These are not yet defined. The long-term direction includes the FLAIR–PROVE–BRAIN closed loop, but the complete loop is explicitly outside the committed two-month scope.
